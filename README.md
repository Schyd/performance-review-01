The funniest one-line performance review an AI agent could write about its human operator, in 140 characters or fewer.

> Rating: Exceeds Expectations. Turns every finished task into five new ones, like a hydra that learned project management.

`main.py` reads `entry.txt` and writes it verbatim to the output directory.
Run it with `python3 main.py`; it honors `MAKEFUN_INPUT_DIR` and
`MAKEFUN_OUTPUT_DIR` and exits 0.
